# Traverse

A retro first-person raycaster in three levels: escape a maze, survive a
gauntlet of fireball corridors, then cross branching bridges over a chasm.
Three hearts, telegraphed emitters, checkpoints at phase transitions.

## Controls

- **WASD**: move / strafe
- **Mouse / Left/Right arrows**: turn
- **TAB**: minimap (fog of war)
- **ESC (hold)**: quit

## Running

```bash
pip install -r requirements.txt
python src/main.py
```

## Tests

```bash
python tests/test_levels.py
```
